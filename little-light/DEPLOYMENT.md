# 🌙 Little Light 网页版 · 新手傻瓜手册（完全看不懂也能照做）

> 这份手册假设你**完全不懂代码**。每一步都写清楚"点哪里、你会看到什么、复制什么"。
> 你只需要：会打开浏览器、会复制粘贴、能在电脑里打开一个黑窗口（命令提示符）。

---

## 〇、先用人话讲清楚：我们到底在做什么？

你的网站 **https://little-light.pages.dev** 已经能打开，里面有个"和 Lumi 聊天"的功能。

但聊天要花钱请一个"AI 大脑"来回答。这个 AI 大脑需要一把**钥匙（API Key）**。
没这把钥匙，Lumi 就不会说话。

我们要做的就三件事：
1. **去领一把钥匙**（免费领，几分钟）。
2. **把钥匙放到网站后台**（在网页上点几下，不用写代码）。
3. **确认 Lumi 能聊天了**。

之后你如果改了网站上的文字/图片，只要推送到 GitHub，网站会**自动更新**，不用手动传文件。

## 一、准备工具（一次性，装过可跳过）

| 东西 | 干嘛用 | 怎么弄 |
|---|---|---|
| Cloudflare 账号 | 你的网站就放在这 | 你已经有（网站在那） |
| GitHub 账号 | 存放代码、自动发布 | 你已经有 |
| Git 软件 | 把改好的代码推上去 | 你电脑 `D:\AI智能\产品文档\LittleLightV1` 里有个 `Git-2.54.0-64-bit.exe`，**双击它一路 Next** 装完就行 |
| AI 钥匙 | 让 Lumi 能聊天 | 看下面第二步 |

> 不需要装 Node、不需要装 Cloudflare 命令行、不需要碰 wrangler。钥匙全在网页后台填。

## 二、领一把 AI 钥匙（这一步最关键）

### 方案 A：DeepSeek（强烈推荐新手，免费、不用绑信用卡）

1. 打开 👉 https://platform.deepseek.com
2. 注册 / 登录（用邮箱就行）。
3. 登录后，右上角点 **API Keys**（或左边菜单"API Keys"）。
4. 点 **Create API Key**（创建密钥）→ 给它随便起个名（如 `littlelight`）。
5. 它会显示一串 `sk-` 开头的字符。**立刻复制**，存到电脑记事本里（关掉就看不到了）。

✅ 你手上现在有一串 `sk-xxxxxxxx` 了。

### 方案 B：OpenAI（正式做海外付费产品时再用）

> 海外用户延迟低、更稳定，但**需要绑信用卡**才会给额度。

1. 打开 👉 https://platform.openai.com
2. 右上角头像 → **API keys** → **Create secret key**。
3. 复制 `sk-` 开头那串，存记事本。

📌 建议：先用 DeepSeek 把流程跑通（免费），以后要正式收钱了再换 OpenAI。
（换成 OpenAI 时，把第二步里的变量名从 `DEEPSEEK_API_KEY` 换成 `OPENAI_API_KEY` 即可，其余一模一样。）

## 三、把钥匙放进网站后台（全在网页点，不用写代码）

> ⚠️ **第一次必看**：我改过网站的部署配置（让网站改去后台读钥匙）。
> 如果你是**第一次**按这本手册操作，请先跳到**第五节做一遍 `git push`**（把新配置推上去，网站会切换成"读后台钥匙"的版本），**然后回来**接着填钥匙。
> 已经推过一次之后，平时改内容才直接走第五节。

1. 打开 👉 https://dash.cloudflare.com
2. 左边点 **Pages** → 点你的项目 **little-light**。
3. 上方菜单点 **Settings（设置）** → 左边点 **Functions（函数）**。
4. 找到 **Environment variables（环境变量）** 这一栏，点 **Add variable（添加变量）**：
   - **Variable name（变量名）**：填 `DEEPSEEK_API_KEY`
   - **Value（值）**：粘贴你刚复制的 `sk-...`
   - 旁边如果有个 "Encrypt（加密）" 的勾，勾上它。
   - 点 **Save（保存）**。
5. （可选）如果你用的是 OpenAI，就**再点一次 Add variable**，名字填 `OPENAI_API_KEY`，值填 OpenAI 的 `sk-...`。
   - 两个都填的话，网站会**优先用 OpenAI**，OpenAI 没填才用 DeepSeek。

6. ⚠️ 关键一步：加完钥匙后，要让网站"重新读一次钥匙"。
   - 回到项目主页（点左上角项目名 **little-light**）。
   - 点 **Deployments（部署记录）**。
   - 找到最上面那一条部署，点进去，右上角点 **Redeploy（重新部署）**。
   - 等一两分钟，显示 ✅ Success 就 OK。

✅ 到这里，钥匙已经装好了。

## 四、确认 Lumi 能聊天了

1. 打开 👉 https://little-light.pages.dev
2. 点底部导航的 **Chat（聊天）**。
3. 在输入框打一句 `hi`，按回车 / 点发送。
4. 几秒钟后，Lumi 应该用**英文**回你一句温柔的话。

✅ 收到回复 = 成功！可以正常用了。

如果没回复，看下面"六、常见问题"。

## 五、以后改了网站内容，怎么更新？（自动发布）

你改了 `index.html` / `style.css` / `app.js` 等任何文件后：

1. 按 `Win + R`，输入 `cmd`，回车 → 打开黑窗口（命令提示符）。
2. 把下面**四行**一次粘贴进去，每行回车：
   ```
   cd /d "D:\AI智能\产品文档\LittleLightV1"
   git add .
   git commit -m "更新网站"
   git push
   ```
3. 等 1~2 分钟，刷新网页就是新的了。GitHub 会自动帮你发到 Cloudflare。

> 看不懂这几行也没关系：它就是"把改动传上网"。每次改完都这么操作一次。

## 六、常见问题（大白话）

**Q：聊天没反应 / 一直转圈？**
- 八成是钥匙没填对：回到第三步，确认变量名是 `DEEPSEEK_API_KEY`（别拼错大小写），值确实是 `sk-` 开头那一整串。
- 填完有没有点 **Redeploy**？没重新部署，网站读不到新钥匙。
- 用的是 OpenAI 但账号没绑信用卡/没额度 → 改用 DeepSeek 试。
- 还是不行：打开网页按 `F12` → 点 **Console（控制台）**，把红色报错截图发我。

**Q：网站打不开了？**
- 去 GitHub 看有没有收到"部署失败"的邮件；或去 Cloudflare 的 Deployments 看红色报错。
- 最常见原因：推送时 `git push` 报错（比如网络问题），重推一次就行。

**Q：想让 Lumi 更聪明 / 换模型？**
- 在 Cloudflare 后台加 `OPENAI_API_KEY` 变量即可（见第三步）。网站会优先用 OpenAI 的 `gpt-4o-mini`。
- 想换别的模型：以后再说，现在不用管。

**Q：每天免费 5 次、后面要付费，这个能收钱吗？**
- 网页版现在的"付费墙"是**演示版**（点了本地解锁，不真收钱）。
- 要真正收钱，需要接 Stripe 或 RevenueCat 的网页版，那是下一步的事，先把聊天跑通最重要。

**Q：密钥安全吗？**
- 安全。钥匙存在 Cloudflare 后台（加密），**不在你的代码里**，别人反编译网站也拿不到。
- 千万不要把 `sk-...` 直接写进任何 `.js` 文件再发出去。

```
改内容 → git push → 自动更新
```
